# Project Vision

## What This Challenge Is About

This challenge is about practicing Test-Driven Development using a small Roman numeral converter library. The main goal is not just to build the converter, but to follow the TDD rhythm: write a failing test, make it pass with the simplest code, then refactor while tests stay green.

The library must convert integers to Roman numerals and Roman numerals back to integers. The problem is small, but it includes useful edge cases like 4, 9, 40, 90, 400, and 900.

## Limits and Scope

- Build a small library, not a full application.
- Write tests before production code.
- Keep each TDD cycle visible in the Git history.
- Use simple code first, then improve it during refactor steps.
- Perform at least two meaningful refactors.
- Reach at least 90% line coverage.
- Document the Roman numeral rules and how to run the project.

## Deliverables

- Library code for Roman numeral conversion.
- Test code covering the expected behavior.
- README with domain rules, setup instructions, test commands, and coverage commands.
- Final coverage report.
- Git history that shows the red-green-refactor process.
